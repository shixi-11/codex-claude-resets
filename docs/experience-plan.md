# 访客信息优先目标

首页只优先回答三个问题：下次什么时候重置，最新相关推文什么时候发布、原文是什么，上次重置什么时候确认。

## 首页层级

1. Codex与Claude分别展示下次公开重置状态。有可靠预告时间才显示倒计时；没有则说明等待公告，不猜测时间。
2. 紧接着展示最新相关推文的发布时间、作者、译文、原文链接和消息类型。正文跟随九种界面语言。未确认线索不冒充重置公告，重置卡不冒充额度恢复。
3. “上次重置公告”直接显示完成公告的发布时间，不把它当成精确重置时刻。更早的三条确认记录默认展开。
4. 更早推文独立排列，不重复每个平台的最新推文。只保留“全部／Codex／Claude”一组筛选；不再重复类别筛选和“最新消息”内标题。默认展开，用上下箭头表示折叠。
5. 下方两张活动卡分别显示品牌、权益类型、赠送内容、适用方案、使用方式、公告或截止时间、来源。重置卡在卡内解释为以后可用的重置机会。取消整段概念说明和强制等高产生的空白。
6. 页尾正常只显示上次成功检查时间。失败或长时间未检查时显示简短提示，不用页面拉取时间替代来源核查时间。删除页脚两句说明以及RSS、JSON、Actions技术入口；公共数据接口继续可用。

## 已撤除

通知、闹钟、邮件订阅、日历提醒、个人额度查询入口，以及展开占屏的通用科普。没有访客订阅数据库，不采集邮箱，不增加邮件寄送服务。

## 收藏夹与标签页

英文名称为Codex & Claude Resets，中文名称为Codex与Claude重置。其他语言采用相应的简短名称，不追加宣传问句。使用同一品牌logo，提供SVG、32px PNG、16/32/48px ICO与Apple Touch图标。

## 验收

九语言与1440、768、390像素屏幕逐一检查。核心时间、最新来源与上次记录直接可见；历史和活动默认展开；自动刷新不改变用户已展开的历史；失联保留最后有效数据；过期核查不维持倒计时。检查线上旧址跳转、图标文件与收藏夹名称。

公开记录由原有GitHub流程在每小时第17、47分计划检查，并在每天02:23 UTC生成汇总。平台调度可能延迟，不承诺严格每30分钟完成。页面每分钟拉取已发布数据，并在重新回到页面时刷新。

新记录通过FxEmbed的公开翻译能力生成译文，缓存绑定原文摘录与内容版本；原文变化使旧译文失效。失败显示原文并标识译文待更新，下次定时检查重试。译文不参与重置状态、倒计时或来源验证。当前记录另行校对术语和语言；未接入付费翻译或X接口，不承诺第三方服务永久免费。
