# Reset topic views

The homepage sums the X view counts of six existing, verified reset announcements across Codex and Claude. `data/topic-heat.json` stores the source URLs, per-post counts and observation time; the homepage source disclosure shows all six links and the date. Counts were retrieved from FxEmbed. They include repeated views and are neither unique people nor this site's traffic. Each tweet collection refreshes these six source counts as one validated snapshot. All six IDs, authors and nonnegative integer view counts must match before the counts and observation time are replaced together. A failure retains the entire previous snapshot. The published page also reloads the snapshot with its regular data refresh. This remains the sum of these six announcements, not an extrapolation to all platforms.

The cheer button keeps the same label on every click and briefly shows +1. It does not store a following preference or change the X view total. Each click triggers a four-hit, alternating two-handed Blender drum animation (48 frames, 30 fps). Clicks during playback queue at most one more round, so rapid taps sustain the rhythm without building an unlimited backlog. Playback finishes at a resting pose. Reduced-motion mode uses an opacity cue. No audio plays.
