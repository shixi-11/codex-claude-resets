# Reset topic views

The homepage sums the X view counts of six existing, verified reset announcements across Codex and Claude. `data/topic-heat.json` stores the source URLs, per-post counts and observation time; the homepage source disclosure shows all six links and the date. Counts were retrieved from FxEmbed. They include repeated views and are neither unique people nor this site's traffic. This is a dated snapshot, not a live counter or an extrapolation to all platforms. Refresh it only with a complete, validated source snapshot.

The cheer button keeps the same label on every click and briefly shows +1. It does not store a following preference or change the X view total. Each click triggers a four-hit, alternating two-handed Blender drum animation (48 frames, 30 fps). Clicks during playback queue at most one more round, so rapid taps sustain the rhythm without building an unlimited backlog. Playback finishes at a resting pose. Reduced-motion mode uses an opacity cue. No audio plays.
