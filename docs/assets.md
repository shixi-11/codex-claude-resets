# Visual assets

The keycap character and charging pad were generated for Codex Respawn with OpenAI image generation on 2026-09-08. Art direction: warm porcelain keycap, two small eyes, two complete feet, a reset arrow and a pale-lime glass pad. The character expresses a pause before returning to work.

`public/assets/mascot.jpg` is the 3840 × 3840 delivery master, resized proportionally from the generated source. This is an upscale, not a claim of native 4K detail. `mascot.webp` is the optimized website derivative. Both preserve the full original composition. The social image is a separate text layout with the same mascot; it does not crop the character.

Manrope and DM Sans are distributed under the SIL Open Font License through their Fontsource packages. Local Windows fonts were checked during selection. The website uses bundled Latin web fonts and system CJK/Arabic fallbacks; no proprietary system font file is redistributed. License notices are included in `public/assets/licenses/`.

The cursor mark is an original SVG. `docs/screenshot.jpg` is a real browser screenshot of the implementation, not the generated concept image.
